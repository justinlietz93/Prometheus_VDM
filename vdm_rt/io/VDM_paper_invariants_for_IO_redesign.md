# VDM / Reading Stack — Cross-Paper Invariants for I/O Redesign

## Core cross-paper invariants

1. **One primitive law, many effective descendants**
   - Later structures are derivative/effective, not new primitives.
   - Application: UTE/UTD must stay interface/effective layers, not contaminate core cognition.

2. **Non-discharge / unresolved burden cannot vanish**
   - If a description drops structure, that burden must reappear somewhere lawful.
   - Application: removing the decoder does not remove articulation burden; it must reappear as a real actuator pathway.

3. **Orthogonal re-articulation under same-domain saturation**
   - When same-domain continuation saturates, continuation must move into a new admissible channel.
   - Application: once lexical prostheses saturate and distort, articulation must move to a different channel class: actuator-space, not token-space.

4. **Visible witness is not state-complete**
   - Surface output is only a projection of deeper carried state.
   - Application: emitted text/speech cannot be treated as the cognition itself; telemetry must preserve pre-release internal articulation state.

5. **Operator-core vs completion branch discipline**
   - Primitive/operator-bearing layers must not be polluted by downstream completion scaffolds.
   - Application: lexicon, Markov chains, phrase templates, and UI convenience renderers must be downstream renderers only, never live cognition.

6. **Selection law / no avoidable excess articulation cost**
   - Selected paths carry no avoidable first-order excess burden.
   - Application: perception and articulation should expose the minimum lawful external structure required for embodiment, not preload convenience abstractions.

7. **Zero-cost directions / conserved burden**
   - True zero-cost directions preserve burden; irreversible limbs relocate it but do not annihilate it.
   - Application: if the model wants to preserve a stream frame or message, it must do so by real external actuation (save, pause, archive), not hidden interface pockets.

8. **Hidden-return correction law**
   - Structure removed from explicit view reappears as compensators/corrections.
   - Application: if UTE coarsens time/order/repetition, cognition will be forced to compensate badly downstream. Better to preserve low-level structure at the boundary.

9. **Measurement is bounded observation, not primitive collapse**
   - Observation is an operational channel with explicit coarse graining.
   - Application: UTE should be a receptor transducer with explicit limits; no magical direct ingestion of “meaning”.

10. **Reversible / irreversible split**
    - Thought formation and output execution are distinct layers.
    - Application: keep internal articulation formation separate from release and from world-facing actuation.

## Reading / language packet invariants

1. **Function follows connectivity and scaffold before specialization**
   - VWFA papers: connectivity precedes function; reading circuits are scaffolded by prior connectivity.
   - Application: do not hardcode a lexicon. Give structured pathways and let specialization emerge.

2. **Cultural recycling / reuse under constraint**
   - Reading recruits older visual/language circuits and inherits their constraints.
   - Application: text I/O should reuse general receptor/actuator pathway logic, not become a special token-engine exception.

3. **Perception is active sampling, not whole-line ingestion**
   - Eye-movement reading work implies sequential fixation, saccades, variable span, selective revisit.
   - Application: text should be exposed as ordered external structure with endogenous pacing and variable aperture.

4. **Stable invariants arise by factorization of variable signal**
   - Infant speech paper: orthogonal feature coding before larger compositional units.
   - Application: medium-native low-level receptor spaces should be preserved first; words/sentences should emerge later, not be forced in at the boundary.

5. **Language network is partly supramodal, but not modality-free at the boundary**
   - Modality-independent language processing exists downstream of modality-specific uptake.
   - Application: shared internal thought/language spaces can exist, but receptors must still remain medium-native.

6. **Hyperlexia / dissociation evidence**
   - Decoding-like skill can dissociate from comprehension.
   - Application: surface text generation/decoding should never be mistaken for cognition.

## Direct implications for UTE / UTD

### UTE
- Continuous media: only current externally available receptor state.
- No hidden replay/history unless backed by a real external recorder/player.
- Static artifacts: may persist only while they truly exist externally.
- Session artifacts: may disappear with the chat/session; then only memory remains unless externally archived.
- Text: preserve order and repetition; no unique-character collapse.
- Text pacing: endogenous.
- Text aperture: variable (grapheme, chunk, word, sentence) but still sequential external order.

### UTD
- No lexicon file, Markov n-gram walk, phrase templates, or sentence macros in the live path.
- Output basis must be a property of the external device, not input history.
- Internal articulation buffer is pre-release state only.
- Release gate must be downstream of model-authored articulation, not the author.
- External persistence must require explicit actuator use.

## Design laws that follow

1. External stays external.
2. Internal stays internal.
3. Nothing crosses except through receptors or actuators.
4. Wall clock is environment/provenance only.
5. Model time is endogenous only.
6. If an external thing disappears, only memory remains unless the model explicitly caused an external save.
7. Tools/devices are external technologies from the model’s perspective; they are not internalized capacities.
