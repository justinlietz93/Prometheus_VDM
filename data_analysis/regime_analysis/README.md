# regime_analysis (organized)

This folder is kept independent from the main `data_analysis/` outputs and contains regime-related tables and bundled deliverables.

## Layout

- `tables/` — CSV tables (regime ticks, microstructure mappings)
- `bundles/` — ZIP bundles (packaged regime analyses)

## Quick entry points

- Start with `tables/regime3_all_ticks.csv` for regime-3 tick-level data.
- Check `tables/regime_emission_microstructure_on_text_ticks.csv` for text-tick microstructure mapping.
- Use `bundles/*.zip` for packaged exports.
