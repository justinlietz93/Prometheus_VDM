# consciousness_metrics (organized)

This folder is kept independent from the main `data_analysis/` outputs and contains dashboard-style consciousness metrics and bundled deliverables.

## Layout

- `tables/` — CSV tables (typically per-epoch dashboards)
- `figures/` — PNG plots (heatmaps, summary visualizations)
- `bundles/` — ZIP bundles (atlases, suites, packaged result sets)

## Quick entry points

- Start with `tables/consciousness_metrics_dashboard_by_epoch*.csv` for primary numeric outputs.
- Start with `figures/consciousness_metrics_dashboard_heatmap*.png` for the corresponding visuals.
- Use `bundles/*.zip` for packaged exports.
