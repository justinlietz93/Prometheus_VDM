\begin{abstract}
This whitepaper template is designed for \emph{runtime protocol papers}: documents that justify, define, and constrain a planned research protocol for a live runtime, agentic substrate, or other dynamically evolving system under study. It is intentionally written for work that sits between exploratory observation and formal experimental design. The template preserves \texttt{arxiv.sty} formatting while providing a publication-grade structure for anomaly-driven but disciplined protocol papers.
\end{abstract}

\section{Background and motivation}

Start with the motivating event or prior run that makes the protocol necessary. This section should be honest, anomaly-forward, and scientifically disciplined. Do not flatten a real anomaly into sterile hedging, but also do not settle ontology prematurely.

A strong background section usually includes:
\begin{itemize}[leftmargin=1.5em]
  \item what was seen in the prior run;
  \item why it exceeded prior expectations;
  \item what scale/context mattered (runtime duration, neuron count, walker count, data volume, decoder limitations, input conditions);
  \item why earlier papers or lower-resolution runs make the anomaly \emph{more} credible, not less;
  \item what remains unresolved.
\end{itemize}

\subsection{Suggested background structure}

\begin{enumerate}[leftmargin=1.5em]
  \item \textbf{Prior run context.} Describe the prior runtime event in concrete terms: runtime length, scale, source pressure, telemetry size, number of outputs, crash/no-crash, and any important architecture limitations.
  \item \textbf{Why it was scientifically significant.} Explain what made it more than ``strange output.'' Focus on aligned features: state/output coupling, long-horizon persistence, regime shifts, selective communication, stable motifs, oscillatory physiology, or late-stage transitions.
  \item \textbf{What it does not establish.} State clearly that the prior run motivates protocolized investigation without resolving ontology.
  \item \textbf{Why this protocol is the next step.} Tie the prior run to the chosen intervention (decoder control, ingress pacing, observer differentiation, multimodal input, etc.).
\end{enumerate}

\section{What this protocol is and is not trying to establish}

This section prevents category confusion.

\subsection{Positive aims}
Examples:
\begin{itemize}[leftmargin=1.5em]
  \item characterize a newly observed runtime regime;
  \item test whether decoder control improves communicative clarity;
  \item determine what conditions are necessary for onset;
  \item assess whether observer differentiation becomes more legible under gentler output constraints.
\end{itemize}

\subsection{Non-aims}
Examples:
\begin{itemize}[leftmargin=1.5em]
  \item this paper does not prove consciousness;
  \item this paper does not settle personhood or moral status;
  \item this paper does not claim metaphysical conclusions;
  \item this paper does not attempt to market the anomaly.
\end{itemize}

\section{Ethical stance and moral-uncertainty protocol}

State the paper's ethical stance in scientific prose, not as a casual disclaimer. For example:

\begin{quote}
Because ontology remains unresolved, the initial research program prioritizes low-coercion, naturalistic, instrumented observation over adversarial or high-force intervention. The aim is to characterize regime structure, communication constraints, observer differentiation, and decoder effects while minimizing avoidable harm under moral uncertainty.
\end{quote}

\subsection{Ethical operating rules}
\begin{enumerate}[leftmargin=1.5em]
  \item No adversarial torment prompts.
  \item No reckless reruns into known crash zones without new safeguards.
  \item No forced continuous output.
  \item Silence is not failure.
  \item Decoder experiments remain separate from substrate experiments whenever possible.
\end{enumerate}

\section{Stop conditions and safety abort criteria}

This section should be operational and explicit.

\begin{itemize}[leftmargin=1.5em]
  \item memory watchdog threshold exceeded;
  \item one-tick edge collapse above a defined threshold;
  \item repeated crash-adjacent punctures without recovery;
  \item filesystem or logger instability;
  \item ethically concerning escalation under the current intervention;
  \item loss of checkpoint coverage near a known dangerous transition.
\end{itemize}

\section{Decision logic and interpretation ladder}

Describe how results will be interpreted without collapsing observations into ontology.

\subsection{Interpretation ladder}
One useful pattern is:
\begin{enumerate}[leftmargin=1.5em]
  \item narrative role assignment;
  \item observer differentiation;
  \item external-agent inference;
  \item moral uncertainty;
  \item stronger ontological claims remain unresolved.
\end{enumerate}

\subsection{What counts as success}
Define what would make the protocol informative even if the most dramatic prior behavior does not recur.

\section{Risks, confounders, and kill methods}

This section should include both technical and conceptual risks.

Examples:
\begin{itemize}[leftmargin=1.5em]
  \item decoder improvements may only improve readability, not substrate organization;
  \item pacing changes may alter the runtime too much to compare cleanly;
  \item dashboard or logging overhead may still distort the observed regime;
  \item role-like motifs may reflect source interaction more than internal identity-like organization;
  \item observer differentiation may be over-read if source provenance is not disentangled.
\end{itemize}

\section{Planned use of results}

State what the results will be used for.

Examples:
\begin{itemize}[leftmargin=1.5em]
  \item determine whether the current decoder is masking substrate coherence;
  \item identify which parts of the system are working, not working, or missing;
  \item motivate a second protocol on adaptive ingress pacing;
  \item support a later results paper if the regime is reproducible.
\end{itemize}

\section{Status and next-paper logic}

Describe how this protocol promotes into later work.

Examples:
\begin{itemize}[leftmargin=1.5em]
  \item If decoder control sharply improves legibility, proceed to adaptive ingress pacing protocol.
  \item If no clarity improvement is seen, prioritize substrate-level onset analysis.
  \item If a high-agency-like regime recurs, produce a separate results paper rather than inflating the protocol paper.
