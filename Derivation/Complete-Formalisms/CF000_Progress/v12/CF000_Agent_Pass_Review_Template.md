# CF000 Agent Pass Review Template
## Harsh Line-by-Line Grading Sheet
### Manager / Auditor Use Only

---

## Purpose

Use this template immediately after every substantial agent return.

This is not a general brainstorming sheet.
It is a hostile grading instrument.

Its job is to answer five questions for every new pass:

1. What did the agent actually claim?
2. Which claims are theorem-grade versus conjectural?
3. Where did the agent smuggle in derived structure?
4. What, if anything, genuinely moved forward?
5. What is the next exact burden to push back on?

This template assumes the CF000_v11_Master_Audit_Checklist remains the master architecture ledger.
This file is the per-pass grading sheet.

---

## Instructions for Use

For each major agent pass:

1. Save the returned artifact files locally.
2. Read the short chat summary last, not first.
3. Review the manuscript in dependency order.
4. Fill this sheet section by section.
5. Do not reward elegance if the pass is contaminated.
6. Do not reward length if the pass avoided the hard burden.
7. Do not reward neat notation if it imports too much.
8. Do not allow “architectural plausibility” to be scored as “proof progress.”

At the end, assign exactly one overall grade:
- Accept for forward integration
- Accept only as partial salvage
- Reject as overpackaged
- Reject as contaminated
- Reject as architecture drift
