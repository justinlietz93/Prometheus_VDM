
# CF000 v16 — DWP Disposition Note

## Verdict

**Outcome C.** Coarse DWP is too coarse and must be split.

## Exact split

v16 separates the old DWP burden into:

1. **WCL — Widening Character Lemma**  
   If a first invariant-bearing differentiated degree is genuinely widened under the same invariant, then the widened articulation is plurality-bearing in the weak internal sense.

2. **WAP — Widening Availability Principle**  
   At least one origin-bearing first invariant-bearing differentiated degree actually admits such genuine widening.

## Dependency verdict

- **WCL:** proved in v16.
- **WAP:** still open; requires one new explicit principle.
- **Multiplicity:** not yet constructively closed, because WAP is not yet proved.
- **Apartness:** still downstream of actual multiplicity.
- **RRP:** still downstream.

## Why the split is real

The character question and the availability question can succeed or fail separately.

A theorem may correctly state what genuine widening would have to look like without proving that widening exists. The old single-line DWP statement blurred those tasks together. v16 stops doing that.
