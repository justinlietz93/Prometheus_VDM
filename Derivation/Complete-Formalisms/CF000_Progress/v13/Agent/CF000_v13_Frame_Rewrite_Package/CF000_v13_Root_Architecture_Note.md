# CF000 v13 Root-Architecture Note

Date: 2026-03-14

## What changed

The manuscript no longer treats WNF, DWP, and RRP as mostly separate burden modules.

It now treats them as three successive formalizations of one governing fact:

> the primitive origin is one condition carrying an unresolved pole-opposition that is never globally discharged.

## How the invariant governs the chain

### WNF
WNF is the first positive manifestation of the invariant.
It answers: once articulation has broken perfect self-coincidence, what is the weakest positive mark of that still-live burden?

### DWP
DWP is the first plurality-bearing articulation of the invariant.
It answers: when the invariant is positively witnessable as internal noncoincidence, must that witness become structured enough to support plurality?

### RRP
RRP is the higher-resolution restatement of the invariant.
It answers: when prior articulation remains locally unsettled, must the same unresolved burden reappear at a more articulated level?

## Why this matters

Without this frame, the manuscript keeps solving hygiene problems while missing the engine.

With this frame:

- non-flatness is no longer read as the whole story,
- witness is no longer read as a detachable certificate,
- recursive refinement is no longer read as an optional second engine,
- and local stability no longer tempts the text into sounding like global resolution.

## Practical consequence for next pass

The next pass should attack WNF first, but under the invariant frame.  
After that, DWP.  
After that, RRP.

That order is not a list of unrelated tasks. It is one burden learning how to speak.
