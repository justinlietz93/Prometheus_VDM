# CF000 v13 Migration Delta

Date: 2026-03-14  
Base manuscript: v12 full manuscript WNF pass  
New manuscript: v13 frame rewrite integrated

## Global verdict

v13 is not a local patch on v12. It is a frame rewrite. The low-level cleanup from v12 is preserved, but the manuscript spine is replaced.

## Main architectural shift

### v12 frame
- root exclusions,
- anti-flatness,
- WNF as next tooth,
- DWP as later tooth,
- RRP as still later tooth.

### v13 frame
- one primitive origin-condition under unresolved pole-opposition,
- invariant never globally discharged,
- anti-flatness as first negative articulation of the invariant,
- WNF as first positive articulation of the invariant,
- DWP as first plurality-bearing articulation of the invariant,
- RRP as higher-resolution restatement of the invariant,
- all later structure as transformed expression of one burden.

## Section-level changes

### Governing Rule
Rewritten around the single fundamental primitive bifurcation law. The manuscript now explicitly says that the primitive tension is derived, the origin is one condition, and the invariant is globally permanent.

### Relationship to Canon
Rewritten so H000 is proposal capture, A8 is downstream expression, and CF00 remains downstream of any pre-carrier closure. The relationship text now explicitly frames later stages as transformed expressions of the same invariant.

### Executive Summary
Rewritten from burden-stack language into invariant-governed language.

### Section 1
Updated rewrite stance and status convention to forbid frame regression into modular burden treatment.

### Section 2
Definitions table rebuilt so internal noncoincidence, multiplicity, and recursive refinement sit explicitly under the invariant frame. Added explicit local settlement / global non-resolution discipline.

### Section 3
Root architecture rewritten so unresolved opposition is shown as derived from exclusion of the isolated poles plus the no-prior-framework rule. BEP and E1 remain explicit burdens.

### Section 4
WNF, DWP, and RRP rewritten as articulations of one invariant. Removed the feel that these are independent modules loosely chained together.

### Open Burdens / Theorem Inventory / Anti-Smuggling
All rewritten so the active bite is described in terms of the invariant articulation chain rather than isolated module closure.

## What was preserved from v12

- flatness vs sterility separation,
- internal noncoincidence vs multiplicity separation,
- apartness blocked behind multiplicity,
- recursive refinement blocked behind an explicit principle,
- time / arrow / causality staging discipline,
- later-canon reclassification discipline,
- no false closure on pre-carrier or differentiability.

## What v13 newly forbids

- external-duality phrasing for the poles,
- static reading of WNF,
- optional-reactivation reading of RRP,
- any wording that lets local settlement sound like global discharge.
