# CF000 v19 — Semantic Budget Note for HRDAP

## Purpose

This note states exactly what semantics are legal inside the live HRDAP burden before that burden closes.

## Current semantic budget

Before HRDAP closes, the manuscript may use only already-earned notions such as:

- origin / origin-bearing realizability,
- flat / non-flat,
- differentiated articulation,
- invariant-bearing articulation,
- lowest-resolution degree after origin,
- schematic higher-resolution differentiated degree target,
- lower-resolution degree not sufficient as sole determination,
- additional internal determination only as a character consequence if admission occurs,
- dependence order,
- local settlement / global non-resolution.

## Blocked imports

The following may not be used to argue for HRDAP:

- apartness,
- contextual noncoincidence as if already closed,
- nodehood,
- branch / tree / graph language,
- locality,
- metricity,
- boundary completion,
- carrier-like support,
- recursive refinement as though already active,
- geometric dimension language,
- any unearned external relation vocabulary.

## Operational rule

If an argument for HRDAP needs one of the blocked meanings, the argument is not yet a proof of HRDAP. It is borrowing semantics from a later stage.
