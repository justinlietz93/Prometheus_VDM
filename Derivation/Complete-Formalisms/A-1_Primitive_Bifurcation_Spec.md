# Definitions and Mechanisms of the Primitive Bifurcation Law

## Definitions

| Term                                          | Exact meaning in the CF stack                                                                                                                                                                                                                                                                                                                            | Software-spec reading                                                                                                                                                                                                      |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Primitive invariant** (\Inv)                | The unique admissible primitive source: unresolved internal opposition between the two terminal poles, borne in one origin-condition. There is only **one** primitive invariant and **one** primitive law.                                                                                                                                               | Never represent two separate primitive objects. Represent **one origin-bearing contradiction** that must remain borne.                                                                                                     |
| **Admitted articulation class** (A_n)         | A lawful domain/class within which the invariant can still be borne without discharge using the currently admitted degrees of freedom and axes. CF000’s declared closure is exactly the staged route (0D \to 1D \to 2D), with later CFs adding later admitted domains.                                                                                   | The current representational support the kernel is allowed to use.                                                                                                                                                         |
| **Same-class articulation**                   | Any continuation that remains wholly inside the currently admitted class (A_n), introduces **no new irreducible support**, and is therefore still reducible to the same-domain possibility space of (A_n). CF000 defines this explicitly at the root as **same-axis** articulation before orthogonal admission is forced.                                | “Try to continue using only what the current support already lawfully provides.” No new axis/domain may be inserted here.                                                                                                  |
| **Same-class saturation** (\mathrm{Sat}(A_n)) | The current class has exhausted all **genuinely new invariant-bearing articulation** available within its own degrees of freedom and axes while unresolved burden remains. The universal axiom states that same-domain saturation is exactly this exhaustion condition. CF000 says 1D same-axis articulation is exhaustively saturable but not terminal. | The kernel’s current support cannot generate any **new lawful continuation** without adding new irreducible structure.                                                                                                     |
| **Discharge** (\mathrm{Dis}(\Inv))            | Terminal settlement of the invariant into either isolated pole, or any operationally equivalent loss of borne unresolved opposition without continued articulation. Both A(-1) and CF000 forbid it for the realized branch.                                                                                                                              | Forbidden terminal states: collapse, erase, reject, NaN-out, settle to one pole, or stop carrying the contradiction.                                                                                                       |
| **Void debt**                                 | The unresolved continuation pressure that begins **exactly at** the saturation limit, when same-domain hosting is exhausted but the invariant remains unresolved. A(-1) defines this constitutionally.                                                                                                                                                   | If bearing remains true but same-class continuation is impossible, set “unresolved continuation pressure” active.                                                                                                          |
| **Minimum protection principle**              | Only the **least additional invariant-bearing machinery** required to keep the invariant borne may be admitted. Later axioms are effective, not primitive.                                                                                                                                                                                               | When extension is forced, choose the **smallest** lawful new support that restores bearing.                                                                                                                                |
| **Boundary hosting**                          | When bulk/same-class hosting is exhausted, unresolved burden concentrates at the limiting same-domain locus rather than disappearing. A(-1) states this constitutionally; CF03 later formalizes boundary-energy concentration; CF08 later shows bulk saturation forcing boundary-hosted modes.                                                           | The old class is not deleted. Its exhausted edge/limit becomes the support from which the next class is admitted.                                                                                                          |
| **Orthogonal re-articulation**                | The forced admission of a **new irreducible articulation class** (A_{n+1}\perp A_n) once `Bear ∧ Sat ∧ ¬Dis` holds. “Orthogonal” here means irreducible to the exhausted class, not yet Euclidean metric orthogonality. CF000 is explicit that pre-metric orthogonality means irreducibility of a new axis/domain relative to the exhausted one.         | Admit a new support form that the previous support could not emulate. Do **not** model this as “branch every loop”; model it as “same support can no longer bear the invariant, so least irreducible extension is forced.” |
| **Codimension-1 interface enrichment**        | Once (A_{n+1}) is admitted, the exhausted (A_n) is retained as the boundary/interface support of the new class. Later CFs witness concrete enrichments: interfaces in CF03, domain walls in CF08, horizons/saturation boundaries in CF12.                                                                                                                | Preserve the old support as an interface object. New structure grows **from** it rather than replacing it.                                                                                                                 |
| **Effective invariant / effective axiom**     | Later invariants and later lawlike closures are not new primitives. They are domain-proper expressions of the same primitive invariant once a new irreducible class is admitted. A(-1) is explicit on this point.                                                                                                                                        | Every new stage must inherit prior burden and add only the minimum new rule needed for continued bearing.                                                                                                                  |

## Mechanisms

| Transition                                       | Exact saturation condition                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Exact forced process to avoid discharge                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Forced result                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0D → 1D**                                      | The admissible origin still bears unresolved two-pole opposition, but **no genuinely new same-class articulation is available** inside the origin-condition itself. There are no internal axes yet; same-domain hosting is exhausted while unresolved burden remains. This is the first constitutional instance of `Bear ∧ Sat ∧ ¬Dis`.                                                                                                                                             | Because the origin cannot discharge into either isolated pole, it must admit the **least continuation that preserves distinction without yet requiring a second axis**. That continuation is **ordered distinguishability / dependence order / serial articulation**. Not geometry yet; just the first lawful “before-after / one-after-another” substrate. CF14 explicitly says dependence order exists **before** time and geometry, and same-domain saturation is logical exhaustion of genuinely new articulation in the current class.  | **1D is forced** as the first serial substrate. This is the origin of lawful succession, serialization, proto-countability, and later number as a readout over repeated articulation. The codim-1 interface is the exhausted origin-condition itself, now functioning as the limiting boundary of the serial branch.                                                                                                                                                    |
| **1D → 2D** *(and codim-1 interface enrichment)* | **Same-axis articulation is saturated.** CF14 states this explicitly: once **1D same-axis articulation is saturated while discharge remains impossible**, a second irreducible axis is forced and 2D is admitted. The 1D class has exhausted all genuinely new invariant-bearing continuation available on a single axis.                                                                                                                                                           | The forced process is **minimum admissible orthogonal re-articulation**: a second axis, not another same-axis repetition. This is the first lawful orthogonal step. The discrete ORS quarter-turn appears here, with the atomic orthogonal articulation algebraically borne by (i), and later the continuous ORS completion appears on the two-axis carrier.                                                                                                                                                                                 | **2D is forced.** Algebra is first licensed here; the ORS quarter-turn is lawful; (i) is the first algebraic witness of the orthogonal step; the continuous ORS orbit later yields the unique least-positive half-turn constant (\pi). The exhausted 1D class is enriched as the **codimension-1 line/interface** inside 2D: it becomes the saturation boundary from which orthogonal rotation and later orbit completion are read.                                     |
| **2D → 3D** *(and codim-1 interface enrichment)* | After 2D is admitted, the invariant can express orthogonal rotation lawfully, but **planar hosting is still finite**: once all genuinely new invariant-bearing articulation available on the two-axis carrier is exhausted while unresolved burden remains, same-plane continuation saturates. The exact constitutional condition is unchanged; the exhausted class is now the **2D plane / orbit-support class**.                                                                  | The forced process is again the **minimum new orthogonal support**. Since 2D already carries the ORS branch, the next admissible continuation is a **third irreducible axis normal to the plane**, so the invariant can continue bearing itself without collapsing back into closed planar exhaustion. This is the next non-flat orthogonal re-articulation.                                                                                                                                                                                 | **3D is forced** as the first fully spatial bulk host. The previous 2D class is enriched as the **codimension-1 surface/interface** inside 3D: not erased, but retained as the boundary-support locus on which saturation, orbit footprints, and later interface energetics can concentrate. CF03’s interface logic is the later formal witness that boundary energy concentrates on codim-1 supports rather than disappearing into the bulk.                           |
| **3D → 4D** *(and codim-1 interface enrichment)* | Once a 3D spatial carrier is admitted, there comes a point where **purely spatial/configurational hosting is insufficient** to continue invariant-bearing articulation without discharge. CF14 states the exact next move: when temporal relation becomes admissible, the same primitive rule is re-expressed on path space. So the saturation condition here is: **3D spatial hosting is exhausted as a sufficient same-class continuation law while unresolved burden remains**.  | The forced process is the admission of a **new domain-proper effective invariant on paths**: not another spatial axis first, but **temporal relation** as the least additional structure required to keep the invariant borne. CF14 closes this as the temporal effective invariant: continuation now proceeds by the minimum admissible accumulated orthogonal articulation on endpoint-fixed admissible paths, yielding stationarity of action.                                                                                            | **4D is forced** as the first spacetime/path-domain host. The codim-1 interface is the **3D hypersurface / endpoint-state slice** inside 4D. In other words, 3D does not disappear; it becomes the boundary data / hypersurface support on which admissible temporal continuation is built. This is where variational physics, Euler–Lagrange balance, and later local field-action stationarity become lawful.                                                         |
| **4D → 5D** *(and codim-1 interface enrichment)* | CF13 gives the exact burden here: once the half-turn of maximal irreconcilability is expressed as an **oriented boundary**, 4D finite/local closure cannot isolate a single chiral half-turn sector under its own hypotheses. That is the saturation condition: **4D closure cannot lawfully host oriented half-turn irreconcilability as an isolated local sector while unresolved burden remains**.                                                                               | The forced process is the same law again: admit the **least orthogonal continuation** that preserves the oriented irreconcilability without discharge. In this branch that is an **auxiliary fifth dimension** whose codim-1 wall hosts the physical chiral mode while the opposite-handed partner is asymptotically separated rather than erased. CF08 is the constructive witness of this mechanism; CF13 gives its invariant interpretation.                                                                                              | **5D is forced** as the furthest dimension the current observable-physics stack explicitly requires in VDM. The codim-1 interface is the **4D oriented wall/boundary** itself, now enriched as the physical chiral hosting locus. The forced result is: chirality as the 5D effective invariant, wall-localized chiral modes, and the domain-wall resolution of the Nielsen–Ninomiya obstruction by asymptotic partner separation rather than illegal finite closure.   |

## Trigger Logic as Software Rules

| Kernel predicate                      | Required meaning                                                                                                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BEAR(current_support)`               | The current support still simultaneously carries both poles and their unresolved unity. Non-bearing is contradictory.                                               |
| `SAME_CLASS_NEWNESS(current_support)` | There still exists at least one **genuinely new** invariant-bearing articulation wholly reducible to the current support.                                           |
| `SAT(current_support)`                | `SAME_CLASS_NEWNESS(current_support) == false` while `BEAR(current_support) == true`. This is not local difficulty; it is exhaustion of same-class lawful capacity. |
| `DISCHARGE`                           | Any collapse, erasure, invalidation, or one-pole settlement of the borne contradiction. Forbidden.                                                                  |
| `LEAST_EXTENSION(current_support)`    | The minimum additional invariant-bearing machinery required by minimum protection to restore lawful bearing once `SAT` holds.                                       |
| `BOUNDARY_HOST(old_support)`          | Preserve the exhausted support as the codim-1 interface/support of the new admitted support, rather than deleting it.                                               |
