# Post-CF15 Closure Index

This folder contains one planning markdown document for each remaining major closure burden discussed after CF15.

## Files

- `CF16_Electroweak_Closure_Plan.md` — electroweak fiber split, chiral weak coupling, neutral mixing, Weinberg angle, W/Z masses, Higgs/interface closure
- `CF17_QCD_Confinement_Closure_Plan.md` — non-abelian confinement, flux tubes, quantitative confinement observable, string breaking, deconfinement
- `CF18_Quantum_Corrections_and_Running_Couplings_Plan.md` — effective action, quantum corrections, running couplings, renormalization, corrected symmetry/anomaly structure

## Recommended sequence

1. CF16 first
2. CF17 second
3. CF18 third

That is the cleanest route to closing the remaining major formal burdens without mixing incompatible proof layers in one paper.
