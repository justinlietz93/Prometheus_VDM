# Post-CF15 Closure Index — Revised

This folder contains one planning markdown document for each remaining major closure burden discussed after CF15.

## Files

- `CF16_Electroweak_Closure_Plan_v2.md` — electroweak fiber split, chiral weak coupling, neutral mixing, Weinberg angle, W/Z masses, Higgs/interface closure
- `CF17_QCD_Confinement_Closure_Plan_v2.md` — strong-force quantitative closure: non-abelian confinement, flux tubes, confinement observable, string breaking, deconfinement
- `CF18_Quantum_Corrections_and_Running_Couplings_Plan_v2.md` — scale-re-articulation branch: effective action, hidden-return corrections, running couplings, renormalization, corrected symmetry/anomaly structure

## Foundation read

- **CF16:** strongest foundation; mostly canon synthesis
- **CF17:** moderate foundation; the strong-force/color branch already exists structurally, but confinement is not yet quantitatively closed
- **CF18:** conceptually strong but formally unwritten; its primitive content is already latent in A(-1), A6, and CF14

## Recommended sequence

1. CF16 first
2. CF17 second
3. CF18 third

That remains the cleanest route to closing the remaining major formal burdens without mixing incompatible proof layers in one paper.
